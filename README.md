### 🤖 TalentFlow AI — AI-Powered Recruitment Automation
An AI-powered recruitment automation system designed to streamline candidate evaluation using LLMs, AI agents, and automated workflows.

- Resume analysis and candidate evaluation
- Agentic AI workflows and recruitment automation
- Built as a technical assessment project for an AI Automation Intern role

**Tech Stack:** React, Node.js, Express.js, MongoDB, OpenAI API, Zod

### 📄 AI Document Intelligence Platform
An AI-powered document intelligence application that helps users retrieve contextual information from documents using semantic search and Retrieval-Augmented Generation.

- Document processing and text embeddings
- Semantic search with HNSW vector indexing
- Context-aware question answering using RAG
- PCA-based vector visualization

**Tech Stack:** Node.js, Express.js, MongoDB, Ollama, Llama 3, nomic-embed-text, HNSW

### 💬 SigmaGPT — AI Chat Application

- Interactive chat interface
- Integration with an AI API
- Full-stack application architecture

**Tech Stack:** MongoDB, Express.js, React, Node.js, OpenAI API

### 📈 Zerodha Clone

- JWT-based authentication
